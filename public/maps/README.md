# Map images

Drop PNG screenshots/renders of real Rocket League arenas in this folder using the exact filenames below
(see `src/data/maps.ts` for the full map list/unlock dates — this file just needs to stay in sync with it).
Landscape, roughly 16:9 works best since these render full-bleed behind a match. A map with no file here
yet just renders with no background image, nothing breaks.
